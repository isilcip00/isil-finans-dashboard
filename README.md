# İsil Finans Dashboard

React tabanlı JavaScript mimarisi ile geliştirilmiş, anlık kripto para verilerini listeleyen ve takip eden modern bir finans paneli (dashboard) uygulaması.

## 🚀 Özellikler

✅ Canlı kripto para verilerinin listelenmesi ve takibi
✅ Veri değişim oranlarına göre dinamik görsel bildirimler (yeşil/kırmızı renk yönetimi)
✅ Üst menü (Navbar) ve listeleme kartları (CryptoCard) ile modüler arayüz
✅ Yönergeye uygun, temiz ve düzenli klasör yapısı
✅ Geleceğe dönük veri modeli genişletilebilirlik altyapısı (Interfaces)

## 📦 Kurulum

Uygulamayı yerel bilgisayarınızda çalıştırmak ve test etmek için aşağıdaki adımları takip edebilirsiniz:

# Bağımlılıkları yükle
npm install

# Geliştirme sunucusunu başlat
npm run start

## 📁 Proje Yapısı

isil-finans-dashboard/
├── public/               # Statik varlıklar ve html dosyası
└── src/                  # Uygulama kaynak kodları
    ├── Components/       # Yeniden kullanılabilir arayüz parçaları (Navbar, CryptoCard)
    ├── Interfaces/       # Veri modeli şablonları ve yapısal tanımlamalar (cryptoInterface)
    ├── Pages/            # Ana ekranlar ve sayfa görünümleri (DashboardPage)
    ├── App.css           # Global tasarım stilleri
    ├── App.js            # Uygulama ana kök bileşeni
    ├── index.css         # Temel element stilleri
    └── index.js          # React uygulamasının giriş noktası

## 🔧 Teknolojiler

* **React** - Bileşen tabanlı kullanıcı arayüzü geliştirme kütüphanesi
* **JavaScript (ES6+)** - Dinamik web programlama dili
* **CSS3** - Esnek ve modern sayfa tasarımları
